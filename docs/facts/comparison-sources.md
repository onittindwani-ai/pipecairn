# Vendor pages read for the tool comparison

Fetched 2026-11-23 for `docs/TOOLS-AND-ALTERNATIVES.md`. Each line says what the page showed that day. Prices and plans change, so read the page again before you decide. Anything not on this list was not checked.

- HubSpot, https://www.hubspot.com/pricing/crm: VERIFIED free for up to 2 users and 1,000 contacts; paid tiers per seat.
- Twenty, https://github.com/twentyhq/twenty and https://twenty.com/pricing: VERIFIED open source, Docker Compose self hosting, self hosting the core is free, hosted plans per seat; licence file says mostly AGPLv3 with some commercial and MIT parts.
- Notion, https://www.notion.com/pricing: VERIFIED free plan with a block cap, paid per member; API access on the free plan was not legible, so UNVERIFIED.
- Calendly, https://www.calendly.com/pricing: VERIFIED free plan with one event type, paid per seat; which plans include the API is not stated, so UNVERIFIED.
- Cal.com, https://cal.com/pricing and the GitHub repo: VERIFIED free plan and per seat paid plans; the root LICENSE file on the main branch (https://raw.githubusercontent.com/calcom/cal.com/main/LICENSE, read 2026-11-23) is the MIT text, copyright Cal.com, Inc., and names no folder with a different licence. The repo page still describes an open core model with enterprise only features, so the open part is: whatever that MIT file covers. Which folders count as enterprise only is UNVERIFIED, so check the licence notes of every folder you self host.
- Google Calendar, https://developers.google.com/workspace/calendar/api/guides/quota: VERIFIED standard use is free, with charges planned only above a daily threshold.
- Twilio, https://www.twilio.com/en-us/sms/pricing/us and Telnyx, https://telnyx.com/pricing/messaging: VERIFIED per message pricing plus carrier fees and number rental. Twilio says 10DLC registration fees apply without a figure.
- SendKit, https://sendkit.ai/what-is-sendkit: VERIFIED a cold email sequencing platform with monthly plans by volume and a 14 day trial. A public API is not confirmed on that page. A different product with the same name offers a developer email API, so check which one you mean.
- InboxKit, https://www.inboxkit.com: VERIFIED mailbox provisioning on Google Workspace and Microsoft 365 with DNS setup and warmup, priced per mailbox.
- Google Workspace sending limits, https://knowledge.workspace.google.com/admin/gmail/gmail-sending-limits-in-google-workspace: VERIFIED limits per user per day exist and can change without notice.
- DocuSign: the vendor pricing page returned an error. Plan and price information came from a search result of vendor regional pages and is UNVERIFIED. The developer page https://developers.docusign.com/docs/esign-rest-api/ shows a REST API.
- Documenso, https://documenso.com/pricing and the GitHub repo: VERIFIED free plan, per month paid plans with API access, self hosting offered, AGPL-3.0.
- Breezedoc, https://breezedoc.com/pricing: VERIFIED a free plan with limits, low one time paid plans, API access listed on all plans.
- Vercel, https://vercel.com/pricing; Railway, https://docs.railway.com/reference/pricing/plans; Hetzner, https://www.hetzner.com/cloud: VERIFIED plan and usage models as described in the comparison.
