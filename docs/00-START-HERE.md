# Start here

Pipecairn answers new leads fast, follows up politely, books calls, and gets a proposal to a signature. It runs on your own machine or server. It starts in a safe mode where nothing is ever really sent.

**Who this is for:** a small business owner or whoever sets up tools for one. You do not need to code to try the demo. You do need to be comfortable pasting commands.

## Pick your path

1. **I just want to see it work.** Read `01-QUICK-DEMO.md`. About 10 minutes. No accounts, no keys.
2. **I want to use it for a real business.** Read `02-BUSINESS-BASICS-CHECK.md` first, then `03-CONNECT-YOUR-TOOLS.md`, `04-ENVIRONMENT-VARIABLES.md`, then pick one of `06`, `07` or `08` to put it online, and finish with `09-GO-LIVE-CHECKLIST.md`.
3. **I am using it for someone else's business.** Read `10-USING-IT-FOR-A-CLIENT.md`.

## What you get

- A dashboard with ten pages: Overview, Pipeline, Inbox, Sequences, Leads, Proposals, Deliverability, Approvals, Integrations, Audit.
- A sending engine with a chain of safety checks that run before every message.
- A reply reader that sorts replies into interested, question, not now, wrong person, unsubscribe, out of office and bounce.
- Proposal and PDF making, and a handoff folder for e-signature.
- A fake company's worth of practice data with planted traps, so you can see the safety gates work.

## What it is not

It is not a way around carrier or email rules. It does not register your texting number for you. It has never been run against real email, text, calendar or CRM accounts, only against copies built from public docs. Read `14-LIMITS-AND-HONEST-NOTES.md` before you trust it with real customers.

## Words you may not know

## Safe mode, in one paragraph

The app has three states: **draft** (it writes messages and moves leads along, but nothing leaves), **live** (it really sends), and **kill switch** (everything stops). The app can move itself toward draft or stop, but it can never turn live sending on by itself. Only you can, by changing a setting on the server.
