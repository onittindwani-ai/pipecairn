# Tools and alternatives

**Read this first.** These scores are judgements, dated 2026-11-23, made from vendor pages fetched that day and from our own adapter work. They are not benchmarks. A tool marked "not run" was scored from its documentation only. Method: `docs/COMPARISON-METHOD.md` in the hub repo: six criteria (fit 35, setup effort 15, reliability and upkeep 15, cost 15, data control 10, integration depth in our adapter 10), each scored 0 to 100 with one evidence line, a weighted total, and closeness (the alternative's fit score divided by the reference tool's fit score). Prices change, so cost is described in plain terms, and a figure appears only where it was read on the vendor page that day, with the link.

The tables below are generated from `data/tool_scores.json` by `python3 tools/score_tools.py`, which also checks the weights and ranges. A unit test fails if the two disagree.

**Re-score of the hub first pass for CRM.** The hub's reading only pass said HubSpot 81, Twenty 77, about 82 percent closeness. With evidence the totals are lower (HubSpot 70.8, Twenty 67.5) and closeness is 90 percent. The totals fell mainly because integration depth was scored honestly: both adapters are thin, HubSpot's was never run live, and Twenty's real input fields are unconfirmed. Closeness rose because the fit criterion here asks what Pipecairn needs from a CRM (a place to mirror contacts and deals), which both tools meet; the first pass had no written evidence to show how it judged fit. The ordering did not change: HubSpot ahead, Twenty close behind.

**How to read closeness.** It asks one thing: does the alternative do this system's job as well as the reference. Above 100 percent means Pipecairn already does that part itself, so the paid tool adds little here. It does not mean the alternative is better in general.
